# Design Tokens

Values are measured from the 1440 px Figma prototype captures. The prototype is WebGL/canvas-rendered, so DOM computed-style extraction is unavailable; raster measurements are used where Figma does not expose values.

- Typeface: Poppins, 400/500/600/700
- Deep green: `#003f27`
- Primary green: `#006b3f`
- Lime: `#7bbf2a`
- Pale mint: `#e8f3ed`
- Teal: `#078f96`
- Body ink: `#202a25`
- Desktop content inset: 38-42 px
- Desktop section spacing: 64-82 px
- Card radius: 10-12 px
- Header height: 82-90 px, fixed, white at top and translucent/blurred when scrolled
- H1 hero: 48-56 px / 1.08; section H2: 34-38 px / 1.2; body: 14-16 px / 1.7
- Hover: translateY(-4px), image scale 1.035, 250-350 ms ease
