# Added pages

132 new local pages use the existing KLK OLEO theme. Existing page layout, typography, colours, images, and animation code are preserved. Edits to existing components only activate links to the new pages.

## New shared page specification

- Shell: existing PrototypePageShell and PrototypePageBanner, unchanged.
- Typography/colour/spacing: existing klk-h1/h2/h4/h6, klk-body/caption, klk-container and klk-section tokens.
- Content: semantic article sections, optional image, source links, responsive related-resources sidebar.
- Desktop: content plus 15rem sidebar at lg; cards2 columns where space permits.
- Mobile: one column, full-width fields, no fixed text/container widths. Inputs at least16 CSS pixels.
- Breadcrumbs: existing shared gradient component.
- Images: original article/company imagery; market hero photos reuse existing industry imagery to keep artwork text from competing with page headings.
- Interactions: new archive category/year filters and pagination, new market ingredient search/filters/pagination, accessible email draft form.
- Enquiry: prepares a user-reviewed regional sales email; it does not submit to an external server.
- Policy documents and live recruitment services stay linked to official source endpoints.
- German/Chinese pages are local source-backed landing pages, not translations of every route.
